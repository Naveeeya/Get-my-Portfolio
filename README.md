# Navya's Journey

An interactive portfolio about the work, ideas, and next chapter of Navya Khanna.

## Visit the website

### [Open Navya's Journey](https://naveeeya.github.io/Get-my-Portfolio/)

The portfolio is designed as a scroll-driven journey through:

- Who I am and what I care about
- My Google Summer of Code 2026 work with GNU Mailman
- Writing, sport, and the things I have shipped
- What comes next

## Built with

- HTML
- CSS
- Vanilla JavaScript
- Canvas animation

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server
```

Then visit [http://localhost:8000](http://localhost:8000).

## Deployment

This project is ready for GitHub Pages. In the repository settings, choose **Pages**, select the `main` branch as the source, and GitHub will publish the site at the link above.
